# 기획: 가족 묶기 · 프로필 · 로그인 · 차 등록

가족 차가 여러 대이고 다른 집도 이 앱을 쓰게 되면, "이 차가 어느 가족 차인지"와 "이 사람이 누구인지"를 알아야 합니다. 이 문서는 그걸 위해 만들 것을 정리합니다.

## 1. 지금 상태와 문제

| 문제 | 지금 | 그래서 생기는 일 |
| :-- | :-- | :-- |
| 가족(서클) 구분 | 앱 안에 서클 ID `home` 하나가 고정 | 이 앱을 깐 모든 차가 같은 "우리집"에 붙음. 다른 집 차에도 우리 메시지가 보임 |
| 프로필 | 서버 첫 실행 때 `seed.json`의 6명이 생김. 차의 사용자 관리에서 이름만 추가·변경 | 사진·호칭이 없음. 새 가족이 스스로 프로필을 만들 방법이 없음 |
| 사람 확인 | 없음. 폰 웹에서 "누구인가요?"를 아무나 고름 | 누구나 다른 사람 이름으로 메시지를 남길 수 있음 |
| 서버 보안 | 주소만 알면 누구나 모든 API를 부를 수 있음 | 인터넷에 올리면 바로 문제가 됨 |
| 차 구분 | 없음 | 어느 차에서 들었는지 모름. 차를 팔아도 계속 붙어 있음 |

## 2. Pleos에서 쓸 수 있는 것 (조사 결과)

- **계정·프로필 SDK는 없습니다.** Pleos Playground가 주는 SDK는 Vehicle State, NaviHelper, FusedLocation, TextToSpeech, SpeechToText, Vehicle Control입니다. Pleos 계정으로 우리 앱에 로그인하는 기능은 문서에 없습니다. 그래서 **로그인과 프로필은 우리 서버에서 직접** 만들어야 합니다.
- **차 고유번호(VIN)는 읽을 수 있습니다.** 쓰고 있는 Vehicle SDK(2.3.2)에 `CarInfo.getVINInfo`가 있습니다. 이걸로 "이 차"를 알아볼 수 있습니다.
  - VIN은 차를 특정하는 정보라, 서버에는 원래 값 대신 **해시값만** 보냅니다.
  - 실차에서 권한 요청이 필요한지는 확인해야 합니다.
- 에뮬레이터의 `ai.pleos.hardware.profile`은 차 하드웨어 설정용 시스템 서비스로 보입니다. 앱이 쓸 수 있는 공개 API는 없습니다.
- **심사 기준:** 개인정보(이름·전화번호·사진)를 받으면 이용 약관, 개인정보 처리 방침, 동의 화면(동의 버튼을 눌러야만 동의), 동의 철회 시 데이터 삭제가 필요합니다.

## 3. 만들 것 한눈에

```
[계정]  폰에서 로그인하는 사람. 1명 = 1계정
   │ 하나 이상
[프로필] 서클 안에서 보이는 모습 (이름·호칭·사진/색). 계정 없는 프로필도 됨 (아이, 폰 안 쓰는 어르신)
   │ 여러 명
[서클]  우리 가족. 초대 코드로 들어옴
   │ 여러 대
[차]    VIN 해시 + 차 이름("아버지 그랜저"). 등록 코드로 서클에 묶음
```

## 4. 프로필

| 항목 | 필수 | 설명 |
| :-- | :-- | :-- |
| 이름 | ✅ | 서클 안에서 부르는 이름. "용민" |
| 호칭 | | 차가 읽어 줄 때 쓰는 말. "아버지", "엄마". 없으면 이름으로 |
| 사진 또는 색 | | 사진을 올리거나, 색 8개 중 하나를 고르면 이름 첫 글자 동그라미로 보임 (지금 홈 화면 얼굴) |
| 연결된 계정 | | 있으면 그 사람이 폰으로 직접 메시지를 남김. 없으면 다른 가족이 대신 관리하는 프로필 |

- **누가 만드나:** 계정이 있는 사람은 가입할 때 자기 프로필을 만들어요. 계정이 없는 가족(아이·어르신)은 서클 관리자가 "가족 추가"로 만들어요.
- **어디서 바꾸나:** 폰 웹이 기본이고, 차에서는 이름·색만 바꿀 수 있어요. 사진 올리기는 폰에서만 해요.
- **지우기:** 본인이 탈퇴하거나 관리자가 빼면, 그 사람이 남긴 메시지·목소리 파일·일기·들은 기록을 함께 지워요. 심사의 동의 철회 조건이에요.

## 5. 흐름

### 5-1. 처음 쓰는 가족 (폰 웹)
1. 로그인합니다. 방식은 6장 참고.
2. 동의 화면(약관·개인정보)에서 동의를 누릅니다.
3. 내 프로필을 만듭니다(이름·호칭·색).
4. 「우리 가족 만들기」 → 서클 이름을 정합니다.
5. 「가족 초대」 → 초대 링크가 생기고 카톡으로 보냅니다. 링크는 7일 동안 쓸 수 있습니다.
6. 폰이 없는 가족은 「가족 추가(계정 없이)」로 프로필만 만듭니다.

### 5-2. 초대받은 가족 (폰 웹)
1. 링크를 엽니다 → 로그인 → 동의 → 내 프로필을 만듭니다.
2. 서클에 들어갑니다. 이미 관리자가 만들어 둔 내 프로필이 있으면 "이 사람이 나예요"로 연결합니다.

### 5-3. 차 등록 (차 + 폰, 차마다 한 번)
1. 처음 켠 차 앱에 "이 차를 가족에 연결해 주세요"와 **6자리 코드 + QR**이 뜹니다. 정차 중에만 보입니다.
2. 폰 웹 「차 추가」에서 코드를 넣거나 QR을 찍습니다.
3. 차 이름을 정합니다("아버지 그랜저").
4. 차 화면이 홈으로 바뀝니다. 이때부터 이 차는 이 서클의 메시지만 받습니다.

코드는 10분 동안 쓸 수 있습니다. 서버는 차에 **차 열쇠(토큰)**를 주고, 차는 이후 모든 요청에 이 열쇠를 붙입니다.

### 5-4. 운전할 때 (차)
- 지금처럼 홈의 가족 얼굴 줄에서 운전자를 누릅니다. **차에서는 로그인하지 않습니다.** 운전석에서 비밀번호를 치는 건 위험하고 불편하기 때문입니다.
- 누가 운전 중인지는 차 열쇠 + 고른 프로필로 서버에 보냅니다. 그래서 "어느 차에서 누가 들었는지"가 남습니다.

### 5-5. 차를 팔거나 바꿀 때
- 폰 웹 「차 관리」에서 「이 차 빼기」를 누르면 그 차의 열쇠가 무효가 됩니다.
- 차 앱 설정의 「이 차 연결 끊기」로도 뺄 수 있고, 차 안에 저장된 기록도 함께 지워집니다.
- 같은 VIN으로 다시 등록하면 새 서클로 들어가고, 이전 서클과는 아무 연결도 남지 않습니다.

## 6. 로그인 방식

| 방식 | 장점 | 단점 | 추천 |
| :-- | :-- | :-- | :-- |
| **초대 코드 + 4자리 PIN** | 외부 서비스 없이 바로 만들 수 있음. 비용 0 | 보안이 약함. PIN을 잊으면 관리자가 재설정해야 함 | **공모전 시연용 1단계** |
| 카카오 로그인 | 가족 대부분이 이미 있음. 비밀번호 없음 | 카카오 개발자 앱 등록·검수 필요 | 2단계 (실제 서비스) |
| 휴대폰 번호 인증 | 누구나 됨 | 문자 발송 비용, 발송 업체 계약 필요 | 2단계 대안 |

**1단계 동작**
- 서클을 만든 사람에게 관리자 PIN이 생깁니다.
- 초대 링크로 들어온 사람은 자기 PIN을 정합니다.
- 다음 접속부터는 이 폰에 로그인 상태가 남고, 바꿀 때만 PIN을 묻습니다.

## 7. 서버에서 바뀌는 것

**새 데이터**

| 데이터 | 내용 |
| :-- | :-- |
| `accounts` | id, 로그인 수단, PIN 해시, 동의 시각 |
| `profiles` | id, circleId, 이름, 호칭, 색, 사진 주소, accountId(없을 수 있음) |
| `circles` | id, 이름, 종류, 관리자 accountId, 초대 코드(만료 시각) |
| `cars` | id, circleId, 차 이름, VIN 해시, 열쇠 해시, 마지막 접속 |
| `pairings` | 6자리 코드, 차 임시 ID, 만료 시각 |
| `heard`에 추가 | carId (어느 차에서 들었는지) |

**API 바뀌는 점**
- 모든 요청에 **열쇠**가 필요합니다. 폰은 로그인 토큰, 차는 차 열쇠를 씁니다.
- 서버는 열쇠로 "어느 서클인지"를 정합니다. 주소의 `circleId`는 믿지 않습니다.
- **메시지 남기기:** 보낸 사람(authorId)을 요청에서 받지 않고 로그인한 프로필로 정합니다. 남이 다른 사람인 척 남길 수 없게 하기 위해서입니다. 차에서 남길 때는 지금 운전자 프로필로 정합니다.
- 새 API: 로그인, 동의, 프로필 CRUD, 사진 올리기, 초대 만들기·수락, 차 등록 코드 발급·확인, 차 빼기, 탈퇴(전부 삭제).
- `https`만 받습니다(배포 서버).

## 8. 화면에서 바뀌는 것

| 어디 | 바뀌는 점 |
| :-- | :-- |
| 차 · 첫 실행 | 「이 차를 가족에 연결해 주세요」 화면 (코드·QR). 등록 전에는 다른 화면이 안 열림 |
| 차 · 홈 | 얼굴 동그라미에 프로필 색·사진이 보임. 인사에 호칭을 씀 |
| 차 · 설정 | 「이 차 이름」, 「이 차 연결 끊기」. 「사용자 관리」는 이름·색 바꾸기만 남기고 추가·빼기는 폰 웹으로 |
| 폰 웹 | 로그인·동의·내 프로필·가족 초대·가족 추가·차 추가·차 관리·탈퇴. 「누구인가요?」 고르기는 없어짐 |

## 9. 만드는 순서

| 단계 | 내용 | 대략 |
| :-- | :-- | :-- |
| 1 | 서버: 서클·프로필·차 데이터 나누기, 열쇠 검사, authorId를 서버에서 정하기 | 1~2일 |
| 2 | 차 등록: 차 앱 연결 화면(코드·QR) + VIN 해시 + 폰 웹 「차 추가」 | 1일 |
| 3 | 폰 웹 로그인(초대 코드 + PIN) · 동의 화면 · 내 프로필 · 초대 | 1~2일 |
| 4 | 프로필 사진·색을 차 홈 얼굴에 반영, 호칭으로 읽기 | 0.5일 |
| 5 | 탈퇴·차 빼기·동의 철회 시 삭제, 약관·처리 방침 문서 | 0.5일 |
| 6 | 서버 배포(https) + 실차 시험 | 별도 |

1~2단계만 해도 "다른 집 차에는 우리 메시지가 안 보인다"가 해결됩니다. 시연 데이터는 지금처럼 시드로 만들고, 시나리오 스크립트가 차 등록까지 자동으로 해 둡니다.

## 10. 정해야 할 것

- 2단계 로그인을 카카오로 할지, 휴대폰 번호로 할지
- 한 사람이 서클 여러 개(우리집 + 처가)에 들어갈 수 있게 할지. 지금 기획은 계정 1개 = 서클 여러 개 가능, 차 1대 = 서클 1개입니다
- 사진 프로필을 1단계에 넣을지. 색만으로도 시연은 충분합니다

## 11. 실차에서 확인할 것

- `getVINInfo`가 실차에서 권한 없이 값을 주는지
- 차에서 QR 화면을 띄우고 폰 카메라로 찍히는지 (화면 밝기·반사)
