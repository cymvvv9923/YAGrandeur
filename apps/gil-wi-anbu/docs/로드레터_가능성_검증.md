# 로드레터 시나리오 v5: 가능성 검증 (2026-11-05)

Pleos Connect 에뮬레이터 v2.1에서 직접 시험한 결과입니다. 시험 코드는 `car-app/.../ProbeReceiver.kt`입니다(디버그 빌드 전용).
판정 기호: ✅ 됨(에뮬레이터에서 확인) · 🟡 될 것으로 보임(실차·마이크·승인 확인 필요) · ⚠️ 바꿔야 함 · ❌ 안 됨

## 2. 시나리오별 판정

### 음성 흐름 (§1, §3-1, §3-3, §4)
| 시나리오 | 판정 | 비고 |
| :-- | :-- | :-- |
| "글레오, 로드레터로 누나한테 메시지 남겨 줘" → 받는 사람을 Gleo가 알아들음 | 🟡 | 기능 선언·수신은 됨. 실제 말 → 우리 기능 연결은 마이크로 확인 필요 |
| "말씀하세요" → 30초 녹음 (주행 중) | ✅ | 마이크 서비스로 주행 중 녹음 가능 확인. Gleo가 말을 끝낸 뒤 바로 녹음을 시작해도 겹치지 않는지는 실차 확인 |
| "누구에게요?" 꼬리질문 | 🟡 | Gleo 응답 `asking` 상태로 가능(문서). 실제 확인 필요 |
| 3초 안에 "취소"/"다시" | 🟡 | 우리 앱이 3초 동안 들어야 함 → 차 안 STT 엔진 또는 서버 STT 필요 |
| 앱이 먼저: "답장할까요?" → "응" | 🟡 | 위와 같음. STT만 되면 가능 (마이크·소리는 주행 중 됨 확인) |
| 주차 직후 "가족에게 남길 말 있으세요?" | 🟡 | P 시점은 잡힘. 대답 듣기는 STT 필요 |
| "누나가 내 메시지 들었어?" / "확인해 줘" | 🟡 | Gleo 기능 하나로 가능. 실제 말로 확인 필요 |
| 녹음 인식 두 번 실패하면 임시저장 | ✅ | 「달리면서 저장한 곳」(임시 저장)이 이미 있음 |
| 조건이 맞으면 앱이 먼저 알리고 재생 (주행 중) | ✅ 만들면 됨 | 주행 중 소리는 됨. 지금 앱은 P에서만 틀어서 주행 중 재생으로 바꿔야 함 |
| 「들었어요」 자동 전달 · 상태 3가지(아직/들었음/답장 있음) | ✅ | 「들었어요」는 이미 있음. 「답장 있음」은 서버에 답장 연결만 더하면 됨 |
| 답장은 원래 장소에서 / 장소 없는 건 다음 시동 때 | ✅ 만들면 됨 | 위치·시동 시점 판단 가능 |

## 3. 운영진(Pleos)에 물어봐야 할 것

1. **STT 서버 사용:** `SpeechToText`의 SERVER/HYBRID 모드에 필요한 **클라이언트 ID·시크릿을 공모전 참가 팀이 발급받을 수 있나요?** 에뮬레이터에서 `Client credentials missing`이 납니다. Playground 어디서 신청하나요?
2. **차 안 STT 엔진:** ON_DEVICE 모드는 에뮬레이터에서 `ON_DEVICE_ENGINE_ERROR`가 납니다. 실차(또는 2차 PT 시연 장비)에서는 동작하나요? 에뮬레이터에 음성 모델을 넣는 방법이 있나요?
3. **Gleo 기능 호출:** `schema.json`은 에뮬레이터 Gleo가 읽었습니다.
   - 공모전 심사·시연에서 **승인(Deliver Schema) 없이도 Gleo가 우리 기능을 부르나요?** 승인이 필요하면 절차와 기간은요?
   - **앱당 기능 3개 제한**을 늘릴 수 있나요? (남기기·확인·답장·취소·여기 저장이 필요)
4. **Gleo 응답 언어:** `APP_ACTION_RESPONSE`의 message는 영어로 정해져 있는데, Gleo가 한국어로 말해 주나요? 아니면 `silent`로 받고 앱이 직접 한국어 TTS를 내도 되나요?
5. **Gleo 이후 녹음:** Gleo가 우리 기능을 부른 직후 우리 앱이 마이크로 30초 녹음해도 되나요? Gleo가 마이크를 놓는 시점을 알 수 있는 신호가 있나요?
6. **앱이 먼저 말 걸기:** 주행 중 우리 앱이 먼저 TTS로 묻고(예: "답장할까요?") 마이크로 대답을 듣는 것이 **주행 규제·심사 기준에 맞나요?** Gleo를 거치지 않고 앱이 직접 해도 되나요?
7. **주행 중 마이크 서비스:** 주행 중 화면 없이 녹음하려고 포그라운드 서비스를 `microphone` 형식으로 켰습니다. Pleos 앱 심사에서 허용되나요?
8. **주행 중 재생:** 조건이 맞으면 주행 중에 가족 목소리를 재생해도 되나요? (화면 없이 소리만) 오디오 포커스 정책은요?
9. **시동 신호:** `IGNITION_STATE`가 지원되지 않습니다. 시동 켬·끔을 알 수 있는 다른 신호(Vehicle SDK·Pleos 서비스)가 있나요? 시동을 끈 직후 몇 초 동안 소리를 낼 수 있나요?
10. **경고등:** 경고등을 읽으려면 `PRIVATE_CAR_SAFETY` 권한이 필요했습니다. 일반 앱이 써도 되는 권한인가요?
11. **계정:** Pleos(현대) 계정으로 앱에 로그인하는 SDK가 있거나 계획이 있나요? 없으면 자체 계정을 써도 되나요?
12. **시연 장비:** 2차 PT에서 마이크가 있는 실차나 시연 장비를 쓸 수 있나요? 에뮬레이터로만 시연해야 하면, Gleo 음성 대신 신호로 흉내 내는 시연도 인정되나요?
