개인정보 처리방침 (초안)

공모전 시연용 초안입니다. 실제 서비스 전에 운영 주체, 연락처, 보관 기간을 확정하고 법률 검토를 받아야 합니다.

1. 무엇을 받나요

항목어디서왜
가족 이름, 구성원 이름·호칭·얼굴 색·사진(선택)폰 웹, 차가족 안에서 누가 남기고 누가 들었는지 보여 주기 위해
메시지 글, 목소리 녹음폰 웹, 차받는 사람 차에서 들려주기 위해
메시지 장소(고른 지점의 좌표와 반경)폰 웹, 차그 근처를 지날 때 메시지를 열기 위해
「들었어요」 기록(누가, 언제, 어느 차에서)차남긴 사람에게 들었다는 것을 알리고, 같은 메시지를 다른 차에서 또 틀지 않기 위해
차의 일기(본인이 공유를 켠 항목만: 달린 거리, 쉬어간 횟수, 들은 메시지, 비·밤길)차가족 소식에 보여 주기 위해
차 고유번호의 해시값, 차 이름차이 차가 어느 가족 차인지 알아보기 위해. 원래 고유번호는 받지 않습니다

2. 받지 않는 것

  • 차의 현재 위치와 다닌 길은 서버로 보내지 않습니다. 메시지 장소 근처인지는 차 안에서만 계산합니다.
  • 옆자리에 누가 탔는지는 차의 일기에만 남고 가족에게 보내지 않습니다.
  • 전화번호, 이메일, 비밀번호는 받지 않습니다 (지금은 로그인이 없습니다).

3. 누가 볼 수 있나요

같은 가족(초대 링크로 들어온 폰과 등록 코드로 연결한 차)만 볼 수 있습니다. 다른 가족이나 제3자에게 주지 않고, 광고에 쓰지 않습니다.

4. 얼마나 보관하나요

가족이 지우기 전까지 보관합니다. 아래 방법으로 언제든 지울 수 있고, 지우면 서버에서 바로 삭제됩니다.

5. 지우는 방법 (동의 철회)

무엇을어떻게함께 지워지는 것
내 메시지폰 웹 「내 메시지」 → 지우기, 또는 차 「소식」 → 내가 남긴 메시지 → 지우기그 메시지의 목소리 파일, 들은 기록
일기 공유차 설정 → 「공유 모두 끄고 기록 삭제」서버에 올린 그 사람의 일기 전부
구성원폰 웹 「모임」 → 고치기 → 이 사람 빼기, 또는 차 설정 → 모임 관리 → 빼기그 사람의 메시지·목소리·사진·일기·들은 기록
차폰 웹 「차 관리」 → 빼기, 또는 차 설정 → 모임 관리 → 모임의 차 → 빼기 (이 차는 「이 차 연결 끊기」)그 차의 열쇠, 차 안에 저장된 오늘 기록
이 폰폰 웹 「모임」 → 이 폰 연결 끊기이 폰의 열쇠
모임 전체폰 웹 「모임」 → 모임 통째로 지우기, 또는 차 설정 → 개인정보 → 모임 통째로 지우기모든 프로필·메시지·목소리·사진·일기·차와 폰의 열쇠

6. 안전하게 지키는 방법

  • 폰과 차는 각자 받은 열쇠로만 자기 가족의 정보에 접근합니다. 서버에는 열쇠 원본이 아니라 해시값만 남깁니다.
  • 목소리 파일과 사진은 짐작할 수 없는 주소에 저장합니다.
  • 실제 서비스에서는 암호화된 연결(https)만 씁니다.
