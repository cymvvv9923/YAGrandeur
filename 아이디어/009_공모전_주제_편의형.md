# 편의형 앱 주제 — Pleos 앱·API·SDK로 운전자의 일을 덜어주는 앱

> 목표: Pleos가 제공하는 기능(Vehicle SDK, NaviHelper, 글레오 연동, AAOS 표준 API)을 엮어 **사용자가 직접 하던 일을 차가 대신 해주는** 앱
> 심사 기준은 `007_공모전_주제_통합정리.md` 6장 기준 (사업성 = 타깃·MAU·Retention·확대 가능성)

## 2. 주제 상세

### 1. 들를 곳 — 용무 경로 비서 ⭐
- **장면**: 퇴근하려고 차에 타자 "가는 길에 세탁소(+3분)랑 약국(+5분) 들를까요?" 카드가 뜨고, 한 번 누르니 경유지 두 곳이 걸린 경로로 출발
- **불편함**: 들를 곳은 휴대폰 메모에 적어두고 잊어버림. 기억나도 운전 중에는 경유지를 넣기 어려움
- **기능**
  - 들를 곳 등록: 휴대폰, 차 화면(정차 중), 글레오 음성("들를 곳에 세탁소 추가")
  - 출발 시 목적지 방향과 영업시간을 따져 **이번 경로에 맞는 용무만** 추천
  - 한 번 탭으로 경유지 포함 경로 실행
  - 경유지에서 기어 P로 정차하면 "세탁소 완료?" → 목록에서 자동 체크
- **쓰는 Pleos 기능**: NaviHelper 목적지·현재 위치·`requestRouteWithWaypoints`, 기어(P/D), 글레오 인터페이스(확장)
- **왜 독립 앱인가**: 내비는 "어디로 갈지"를 알지만 "무엇을 해야 하는지"는 모름. 할 일과 경로를 이어주는 앱이 없음
- **확대 계획**: 가족 공유 목록("우유 사 와"), 택배 보관함·주차장 정보, 제휴 매장 픽업

### 2. 주유 타이밍 비서 ⭐
- **장면**: 금요일 저녁 강릉 경로를 잡자 "가는 건 충분하지만 돌아올 연료가 부족해요. 경로상 횡성휴게소 주유소가 리터당 70원 싸요" → 경유지 추가
- **불편함**: 연료 경고등이 켜진 뒤에 급하게 비싼 주유소에 들르게 됨. 주유 기록은 아무도 안 남김
- **기능**
  - 연료량 × 연비 vs 남은 경로 거리 → "목적지까지 충분 / 돌아올 때 부족" 판단
  - 경로상 최저가 주유소 추천 (오피넷 유가 Open API) → 경유지로 추가
  - 연료량이 급증하고 "주유 후 주행거리"가 0으로 바뀌면 주유로 자동 인식 → 주유 기록·월 절약액
- **쓰는 Pleos 기능**: Fuel 연료량·연비, Odometer 주유 후 주행거리, NaviHelper 남은 거리·경유지
- **왜 독립 앱인가**: 휴대폰 유가 앱은 내 차 연료량과 경로를 모름. 차가 "언제 넣어야 하는지"까지 판단
- **주의**: 내비의 주유소 검색과 겹쳐 보일 수 있음 → **연료량 기반 판단 + 자동 기록**을 핵심으로
- **확대 계획**: 주유 제휴 할인, 하이브리드 연비 리포트, EV 차종은 충전 계획(NaviHelper charging-plan)으로 확장

### 3. 경고등 도우미
- **장면**: 계기판에 처음 보는 노란 경고등이 켜짐. 정차하자 "타이어 공기압 낮음 · 오늘 안에 점검 권장 · 3km 앞 블루핸즈" 카드
- **불편함**: 경고등 모양만 보고는 뜻도, 얼마나 급한지도 모름. 설명서를 찾을 수도 없음
- **기능**
  - 경고등·타이어·엔진오일·브레이크액·워셔액 신호를 쉬운 말로 설명
  - 급한 정도 3단계 (바로 정차 / 오늘 안에 / 다음 정비 때)
  - 가까운 정비소를 목적지로 설정, 해결되면 기록
- **쓰는 Pleos 기능**: Safety 경고등(Telltales), Tire, 오일·브레이크액·워셔액, NaviHelper 경로
- **약점**: 경고등이 자주 뜨지 않아 다시 열 일이 적음 → 007의 **카히스토리**와 합쳐 "내 차 건강" 앱으로 만들면 Retention 보완
- **주의**: 글레오가 차량 설명서 질문에 이미 답할 수 있다면 겹침 → 차량 상태와 연결된 **조치·연결**에 집중

### 4. 장거리 출발 점검
- **장면**: 명절에 부산까지 경로를 잡자 "출발 전 점검: 워셔액 부족(경로에 비 예보), 타이어 정상, 연료 1회 주유 필요"
- **기능**: 경로 탐색 완료 시 거리가 길면 자동 점검 → 연료·타이어·워셔액·경고등 + 목적지 날씨 → 필요한 주유·정비를 경유지로 제안
- **쓰는 Pleos 기능**: NaviHelper 경로 탐색 완료·남은 거리, Fuel, Tire, 워셔액, 경고등
- **참고**: 2·3과 엔진이 같아 하나의 앱 안에서 자연스럽게 묶임

### 5. 출발 비서 — 1~4를 하나로 ⭐ (묶음 제안)
- **장면**: 아침에 시동을 걸면 카드 한 장 — "회사까지 32분 · 가는 길에 택배 보관함 · 연료는 내일 주유 권장 · 차 상태 정상"
- **왜 묶나**
  - 들를 곳(1)은 자주 쓰고, 주유(2)는 주 1회, 경고등(3)은 가끔 → **합치면 매일 여는 앱**이 됨 (Retention)
  - 모두 "차에 타는 순간"이라는 같은 진입점을 가짐
- **주의**: 범위가 넓어지면 "내비의 기능 모음"처럼 보일 수 있음 → 기획서에서는 **들를 곳(1)을 대표 기능**으로 세우고 나머지는 같은 카드에 붙는 보조 기능으로 설명

### 6. 차 안 음성 메모 (➖)
- "글레오, 메모해 줘 — 내일 견적서 보내기" → 시각·위치·주행 중 여부를 붙여 저장, 정차 중이나 휴대폰에서 확인
- 도착 연동 리마인더: "회사 도착하면 알려줘" → 목적지 도착(기어 P) 시 알림
- **약점**: 휴대폰 음성 비서와 차별점이 약함. 글레오 인터페이스가 공모전 에뮬레이터에서 동작하는지 미확인

### 7. 도착 맞춤 집 준비 (❌)
- 도착 10분 전 집 에어컨·보일러 켜기, 출발 시 집 조명 꺼짐 확인 (스마트홈 Open API)
- **제외 이유**: 현대차가 기존 커넥티드 서비스로 차-집 연동을 제공하고 있을 가능성이 높고, 외부 스마트홈 연동은 시연 부담이 큼

### 8. 요일별 출발 루틴 (➖)
- 반복 이동 패턴(요일·시간·목적지)을 학습해 시동 시 한 번 탭 경로
- **약점**: 내비의 최근 목적지·추천과 겹침 → 5 출발 비서의 카드 한 줄로 흡수

### 정리
- **1순위 들를 곳**: 사용자가 가장 많고, 내비에 일을 시키는 NaviHelper 기능을 핵심으로 써서 기술 활용성이 분명함
- **2순위 주유 타이밍 비서**: 차만 아는 연료 데이터로 판단하는 앱이라 차량특화성이 가장 확실함
- **묶음 제안 출발 비서**: 들를 곳을 대표 기능으로, 주유·경고등·장거리 점검을 붙이면 매일 여는 앱이 되어 Retention 논리가 강해짐
- **글레오 연동**은 어떤 주제에 붙여도 가산 요소가 되지만, 에뮬레이터에서 동작하는지 먼저 확인해야 함

### 에뮬레이터로 확인할 것
- 글레오 인터페이스가 Pleos Connect Emulator 2.1.0에서 동작하는지 (App Schema 등록 방법 포함)
- `requestRouteWithWaypoints`로 경유지 포함 경로가 에뮬레이터 내비에 실제로 걸리는지
- Virtual Console에서 연료량·경고등을 바꿀 수 있는지
