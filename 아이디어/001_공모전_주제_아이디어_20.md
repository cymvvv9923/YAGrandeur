## A. 스마트 드라이빙 & 안전

### 1. 졸음·피로 케어 음성 코파일럿
- **페인포인트**: 장거리·심야 운전 시 졸음운전 위험. 혼자 운전할 때 각성 수단이 없음
- **기능**: 연속 주행 시간·시간대·속도 변동 패턴으로 피로도를 추정 → 위험 시 음성 대화(끝말잇기, 퀴즈)로 각성 유도 → 가장 가까운 휴게소/졸음쉼터로 경로 안내
- **차량특화**: 주행 데이터 기반 실시간 판단 + 손을 쓰지 않는 음성 상호작용
- **사업성**: 화물·택시·장거리 출퇴근자. 보험사/물류사 B2B 연계

### 2. 초보운전 위험구간 프리뷰
- **페인포인트**: 초보 운전자는 급커브, 합류 구간, 어린이보호구역에 갑자기 진입하면 당황함
- **기능**: 경로상 위험 구간을 미리 파악해 진입 전 음성으로 예고("500m 앞 왼쪽 합류, 미리 1차로로") → 주행 후 구간별 운전 리포트
- **차량특화**: 내비 경로와 실시간 위치를 결합한 선제적 안내
- **사업성**: 매년 신규 면허 취득자, 운전연수 업체·렌터카 제휴

### 3. 시니어 드라이버 케어 리포트
- **페인포인트**: 고령 운전자의 운전 능력 변화를 본인과 가족이 객관적으로 알기 어려움
- **기능**: 급제동 빈도, 평균 속도 편차, 경로 이탈 횟수 등의 장기 추이를 분석 → 자녀에게 주간 리포트 공유, 야간·악천후 운전 자제 권고
- **차량특화**: 차량 데이터 없이는 불가능한 장기 패턴 분석
- **사업성**: 고령 운전자 증가(사회 이슈), 지자체·보험사 연계 가능

### 4. 차량 컨디션 다이어리
- **페인포인트**: 엔진오일, 타이어, 와이퍼 등 소모품 교체 시점을 놓침
- **기능**: 주행거리·운전 습관 기반으로 교체 시기 예측 → 정차 시 알림 → 주변 정비소 안내 및 정비 이력 기록
- **차량특화**: 실제 주행 데이터 기반 예측(모바일 앱은 수동 입력)
- **사업성**: 정비 네트워크·부품 커머스 수수료

### 5. EV 전비 코치
- **페인포인트**: EV 운전자는 주행 가능 거리 불안이 크고, 전비를 올리는 운전법을 모름
- **기능**: 가감속·회생제동 패턴을 실시간 분석해 음성 코칭 → 남은 경로 대비 도착 시 배터리 예측 → 주간 전비 랭킹/배지
- **차량특화**: 배터리·주행 데이터 + 경로 결합
- **사업성**: 현대차그룹 EV 라인업 확대와 직접 맞닿음, 게이미피케이션으로 리텐션 확보

## B. 모빌리티 & 라이프 편의

### 6. 경로 연동 픽업 사전주문
- **페인포인트**: 출근길 커피·포장 음식을 주문하려면 정차하고 휴대폰을 조작해야 함
- **기능**: 경로상 매장 추천 → 음성 주문 → 도착 예정 시간에 맞춰 조리 시작 → 도착 시 픽업 알림
- **차량특화**: 내비 ETA로 조리 타이밍 동기화(모바일 대비 확실한 우위)
- **사업성**: 주문 수수료, F&B 프랜차이즈 제휴. 구현 범위는 Mock 매장 API로 시연

### 7. 스마트 주차 메모 & 요금 타이머
- **페인포인트**: 대형 주차장에서 내 차 위치를 잊음, 주차 요금 초과
- **기능**: 시동 OFF·P단 감지 시 위치 자동 저장 + 음성으로 층/구역 메모("B3 파란 기둥") → 무료 주차 시간 만료 전 알림
- **차량특화**: 차량 상태(기어/시동)로 자동 트리거
- **사업성**: 주차장 플랫폼 제휴. 구현 쉬워 MVP용으로 적합

### 8. EV 충전 대기 플래너
- **페인포인트**: 충전소를 찾는 것도, 충전 대기 30분을 보내는 것도 비효율적
- **기능**: 배터리 잔량과 경로로 최적 충전 지점 추천 → 충전 중 주변 카페·짧은 콘텐츠·업무 큐레이션 → 충전 완료 예상 알림
- **차량특화**: 배터리 상태 + 경로 + 정차 맥락
- **사업성**: 충전 사업자·주변 상권 광고

### 9. 위치 기반 음성 리마인더
- **페인포인트**: "퇴근길에 세탁소 들러야지"를 매번 잊음
- **기능**: 음성으로 "마트 근처 지나가면 우유 사라고 알려줘" 등록 → 지오펜스 진입 시 TTS 알림 → 경유지 추가 제안
- **차량특화**: 운전 중 손을 쓰지 않는 등록, 경로상 경유지 자동 삽입
- **사업성**: 생활 밀착형으로 높은 DAU, 위치 기반 광고

### 10. 법인차 운행일지 자동화
- **페인포인트**: 법인차 비용을 처리하려면 운행기록부를 써야 하는데 수기 작성이 번거로움
- **기능**: 출발·도착 시각, 주행거리, 경로를 자동 기록 → 음성으로 운행 목적 태깅("거래처 미팅") → 국세청 양식 엑셀로 내보내기
- **차량특화**: 차량 주행 데이터 자동 수집
- **사업성**: **명확한 B2B 수요**(법인·개인사업자), SaaS 구독 모델. 사업성 점수에 유리

### 11. 출퇴근 ETA 공유 & 루틴 자동화
- **페인포인트**: 가족에게 "언제 와?" 연락이 오고, 귀가 전 집안 준비가 안 됨
- **기능**: 출발 감지 시 가족에게 ETA 자동 공유 → 도착 10분 전 스마트홈 연동(에어컨·조명) 트리거 → 정체 시 지연 자동 알림
- **차량특화**: 출발·도착을 차량 상태로 정확히 감지
- **사업성**: 스마트홈 생태계 연계(그룹사 시너지)

## C. 인카 엔터테인먼트

### 12. 로드트립 오디오 도슨트
- **페인포인트**: 여행 중 지나치는 지역의 이야기를 모르고 그냥 지나침
- **기능**: 현재 위치·진행 방향 기반으로 지역 역사, 명소, 맛집 이야기를 TTS로 자동 재생(LLM 생성) → 관심 있으면 음성으로 "거기 가자" → 경유지 추가
- **차량특화**: 위치와 속도에 맞춰 이야기 타이밍 조절
- **사업성**: 지자체 관광 홍보 제휴, 지역 상권 광고

### 13. 주행 맥락 AI DJ
- **페인포인트**: 음악 추천이 주행 상황(정체, 고속도로, 야간, 비)과 무관함
- **기능**: 속도, 시간대, 날씨, 목적지 유형으로 플레이리스트 생성 + 곡 사이 AI DJ 멘트(교통 상황, 도착 시간 안내)
- **차량특화**: 주행 맥락이 핵심 입력값
- **사업성**: 음원 플랫폼 제휴, 프리미엄 구독

### 14. 출퇴근 음성 회화 학습
- **페인포인트**: 매일 1시간 출퇴근 시간이 버려짐
- **기능**: STT/TTS로 영어 회화 롤플레이 → 정체·고속 등 주행 상태에 따라 난이도·대화 길이 자동 조절 → 정차 시에만 화면에 단어 카드 표시
- **차량특화**: 주행 부하에 따라 학습 강도를 조절(안전 + 차별화)
- **사업성**: 교육 구독 모델, 높은 습관성(리텐션)

### 15. 드라이브 여행 자동 기록
- **페인포인트**: 여행 후 어디를 들렀는지 정리하기 귀찮음
- **기능**: 경로와 정차 지점을 자동 기록 → 정차 시 음성 한 줄 메모 → 여행 후 지도 타임라인·SNS용 카드 자동 생성
- **차량특화**: 정차·시동 이벤트 기반 자동 기록
- **사업성**: 여행 커뮤니티, 숏폼 챌린지와도 연계하기 쉬움

## D. 패밀리 & 동승자 케어

### 16. 키즈 창밖 퀴즈
- **페인포인트**: 장거리 이동 중 아이들이 지루해하고, 결국 스마트폰만 봄
- **기능**: 현재 위치 주변(강, 산, 랜드마크)을 소재로 한 음성 퀴즈 → 아이가 음성으로 답변 → 여행 완료 시 "탐험 배지" 수집
- **차량특화**: 실시간 위치와 창밖 풍경을 연결한 학습형 놀이
- **사업성**: 가족 단위 고객, 교육 콘텐츠 제휴

### 17. 반려동물 동승 케어
- **페인포인트**: 반려동물을 태우면 휴식 타이밍, 실내 온도, 동반 가능 장소가 걱정됨
- **기능**: 주행 시간 기반 휴식 알림 → 반려동물 동반 가능 휴게소·카페 안내 → 차내 온도 모니터링 알림(SDK 지원 시)
- **차량특화**: 차량 상태와 경로 결합
- **사업성**: 반려가구 1,500만 시장, 펫 커머스 제휴

### 18. 가족 장거리 휴게 플래너
- **페인포인트**: 명절·여행 장거리에서 "화장실 언제 가?", "배고파"로 계획 없이 정차함
- **기능**: 출발 전 동승자 구성 입력(유아, 어르신) → 최적 휴게 지점 사전 플랜 → 동승자가 음성으로 요청하면 다음 휴게소의 편의시설·메뉴 안내
- **차량특화**: 경로 기반 휴게 일정 최적화
- **사업성**: 휴게소·고속도로 운영사 제휴, 명절 시즌 바이럴

## E. B2B & 기타

### 19. 현장 기사 음성 업무기록
- **페인포인트**: 방문 AS·영업 사원은 하루에 여러 곳을 돌며 이동 중 기록과 다음 방문 준비를 함
- **기능**: 방문 일정을 경로로 최적화 → 방문 종료 후 음성으로 업무 보고 → 텍스트 요약 → CRM 연동, 다음 고객 정보 TTS 브리핑
- **차량특화**: 이동 시간을 업무 시간으로 전환
- **사업성**: 기업 SaaS(필드 서비스 관리), 객단가 높음

### 20. 차박·캠핑 모드
- **페인포인트**: 차박 시 배터리 방전 걱정, 주변 편의시설 정보 부족
- **기능**: 정차 장시간 감지 시 캠핑 모드로 전환 → 배터리 잔량 관리 가이드 → 주변 화장실·편의점 안내 → 수면 사운드
- **차량특화**: 차량 배터리·상태 데이터가 핵심
- **사업성**: 차박 인구 증가, 캠핑용품 커머스
