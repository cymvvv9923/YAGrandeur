# 주제 후보 풀 (주제 확정 전 탐색용)

> 기획서 초안은 주제가 확정된 뒤에 작성합니다. 이 문서는 후보를 넓게 펼쳐 보는 용도입니다.
> 공통 조건: **많은 사용자** · **기존 앱(내비·멜론·마이현대)의 기능 하나가 아닌 독립 앱** · **차에서만 가능한 가치** · **지금 쓸 수 있는 SDK(Vehicle 조회 + NaviHelper)로 핵심 구현**
> SDK 상태와 대회 규정은 **0장에서 직접 확인한 결과**로 판정했습니다.

## 0. 직접 확인한 SDK·규정 (2026-10-27)

출처: Pleos Playground 문서(document.pleos.ai)의 Vehicle·NaviHelper API 레퍼런스, 프로젝트 생성 및 SDK 신청 문서, 앱 심사 가이드, 공모전 이용약관

### 0-1. SDK 제공 상태
| SDK | 상태 |
|---|---|
| Vehicle **조회**(get·register) | ✅ 신청 없이 바로 사용 |

| 연료량·주유 후 주행거리 | ✅ | Fuel `fuel-percent`, Odometer `trip-since-refill` → **주유 시점 추정 가능** |

### 0-3. 규정 확인
| 질문 | 결과 | 근거 |
|---|---|---|
| 외부 서버·외부 API 사용 | ✅ 금지 조항 없음 | 이용약관: 사용 권한만 적법하게 보유하면 됨 (제7조 2항) |
| 휴대폰 짝 앱 | ✅ 금지 조항 없음 | 단, 심사·시연 대상은 차량용 APK. 기술 활용성은 Pleos SDK 중심으로 평가 |

| 백그라운드 동작 | ⚠️ | 백그라운드 리소스 최소화 원칙. 콜백 구독은 가능 |

| 현재 위치를 경로 안내 없이도 받는지 | ❓ 문서로는 불명확 | `route-id` 필드가 있어 안내 중에만 올 가능성 있음 |

## A. 정차 공간형 — "차를 세웠을 때 생기는 새로운 시간"

> 공통 강점: 정차 전용이라 주행 중 규제 부담이 거의 없고, "차는 공간"이라는 SDV 비전과 맞음

### 1. 차 안 쉼 — 정차 중 파워냅·휴식
- **대표 장면**: 점심시간 회사 주차장에서 시트를 젖히자 "20분 쉬어갈까요?" 카드가 뜸
- **핵심 기능**
  - 기어 P + 시트 젖힘 감지 → 휴식 모드 자동 제안
  - 내기순환 장시간·창문·문 잠금·배터리/연료 소모 안전 점검
  - 파워냅 타이머, 백색소음, 기상 후 다음 목적지 연결
- **차량 데이터**: 기어, Seat 각도, HVAC 내외기, Door, Window, Fuel·EvBattery
- **독립 앱인 이유**: "차에서 쉬는 시간"을 다루는 앱 자체가 없음

### 2. 드라이버 바디케어 — 운전 자세 교정 + 휴식 스트레칭
- **대표 장면**: 2시간 운전 후 휴게소에 서자 "허리 많이 쓰셨어요, 시트에서 3분 스트레칭" 안내
- **핵심 기능**
  - 시트 위치·등받이 각도·핸들 상태로 **내 운전 자세 점수** (너무 뒤로 누움, 너무 앞으로 당김)
  - 연속 운전 시간·트립 거리 누적 → 정차 시 맞춤 스트레칭 루틴
  - 주간 "운전 피로 리포트"
- **차량 데이터**: Seat 위치·각도, Steeringwheel, Odometer 트립 시간, 기어
- **독립 앱인 이유**: 휴대폰은 내 운전 자세를 모름. 건강 카테고리로 새로 생기는 앱
- **리스크**: 자세 기준은 인체공학 자료를 근거로 써야 함

### 3. 차박 매니저 — 차박 밤샘을 안전하게
- **대표 장면**: 차박지에 도착해 시동을 끄자 "오늘 밤 배터리로 공조 6시간 가능" 표시
- **핵심 기능**
  - 배터리·연료로 밤새 공조·전원 사용 가능 시간 계산 (EV 특화)
  - 환기·문 잠금·창문 점검, 아침 알람
  - 차박지 후기 커뮤니티 + 다음 차박지 경로 바로 실행
- **차량 데이터**: EvBattery SOC, Fuel, HVAC, Door, Window, NaviHelper
- **차 안 쉼과의 관계**: 같은 엔진으로 만든 "장시간 버전". 하나의 앱 안에 모드로 넣을 수도 있음

## B. 소셜·관계형 — "차를 중심으로 생기는 새로운 관계"

### 4. 드라이브로그 — 운전자를 위한 Strava
- **대표 장면**: 친구가 올린 "가을 단풍 북한강 코스"를 누르니 경유지 5개가 그대로 내비에 걸림
- **핵심 기능**
  - 트립 자동 기록 (기어·도어로 시작·종료, 거리·시간·외기온도·연비)
  - 코스 공유 → 한 번 탭으로 경유지 포함 경로 실행 (`requestRouteWithWaypoints`)
  - 전국 도로 정복 지도·배지, 계절 코스 랭킹
- **독립 앱인 이유**: 앱 마켓에 소셜 카테고리가 비어 있음. 사용자가 코스를 만들며 성장
- **리스크**: 위치 SDK는 준비 중이지만 NaviHelper `onCurrentLocationInfo`로 위도·경도를 받을 수 있음. 경로 안내 중이 아닐 때도 오는지는 에뮬레이터로 확인 필요

### 5. 우리집 차 같이 쓰기 — 차 한 대를 나눠 쓰는 가족 앱
- **대표 장면**: 엄마가 차에 타자 "아빠가 연료 20% 남겨뒀어요, 내일 아침 아들 예약 있음"
- **핵심 기능**
  - 가족 차량 예약 캘린더 (누가 언제 쓰나)
  - **시트 위치로 운전자 자동 식별** → 운전자별 주행 기록
  - 반납 매너 체크: 연료·배터리 잔량, 문 잠금, 트렁크 → 다음 사람에게 알림
- **차량 데이터**: Seat 위치, Fuel·EvBattery, Door, Odometer
- **독립 앱인 이유**: 가족 간 차량 공유를 다루는 앱이 없음. 국내 1가구 1차량 가정이 많아 사용자층이 넓음
- **리스크**: 차에 타지 않은 가족은 휴대폰으로 봐야 하므로 모바일 짝 앱이 필요

## C. 자산·돈형 — "내 차의 가치를 지키는 앱"

### 6. 카히스토리 — 팔 때 제값 받는 내 차 관리 인증서
- **대표 장면**: 4년 뒤 중고로 팔 때 "급가속 적음 · 경고등 즉시 조치 · 타이어 관리 A등급" 인증서를 매물에 첨부
- **핵심 기능**
  - 주행 습관(가감속·브레이크), 경고등 발생과 해결 시간, 타이어 공기압 관리, 주행거리를 상시 기록
  - 위변조할 수 없는 "차량 관리 이력서" 생성 (VIN 기반)
  - 현재 예상 시세와 관리 점수 → 시세 영향 안내
- **차량 데이터**: Safety 경고등, Tire, Brake, Odometer, CarInfo VIN, 속도
- **독립 앱인 이유**: 중고차 시장의 정보 비대칭이라는 큰 문제를 차 데이터로 푸는 새 서비스
- **PM 포인트**: 현대 인증중고차와 연결하면 잔존가치·재구매 퍼널
- **리스크**: 인증서의 신뢰를 누가 보증하는지(주최측·제휴사) 설계 필요

### 7. 세차 타이밍 — "지금 세차해도 될까?"
- **대표 장면**: "이번 주 와이퍼를 40분 썼고 염화칼슘 도로를 120km 달렸어요. 내일부터 3일 맑음, 오늘 세차 추천"
- **핵심 기능**
  - 와이퍼 사용량(비 노출), 주행거리, 외기온도(겨울 제설제 시즌)로 오염도 추정
  - 날씨 예보와 결합한 세차 최적일 추천
  - 경로상 세차장을 경유지로 추가, 세차 기록
- **차량 데이터**: Wiper, Odometer, HVAC 외기온도, NaviHelper
- **독립 앱인 이유**: 세차는 모든 오너의 반복 행동인데, 차 데이터로 타이밍을 알려주는 앱은 없음
- **리스크**: 단일 기능이라 가벼워 보일 수 있음 → 세차장 예약·구독 커머스로 확장 필요

### 8. 자동 가계부 (이전 1위, 참고용)
- 주유·충전·통행료·트립을 자동 기록. 단, 마이현대 기능과 겹침
- 확인 결과: 주유는 연료량·"주유 후 주행거리"로 추정 가능, **하이패스 통행 이벤트는 SDK에 없음**(경로 예상 통행료만 가능)

## D. 이동 시간 활용형 — "주행 중 버려지는 시간"

### 9. 도착 맞춤 오디오 — 도착할 때 딱 끝나는 콘텐츠
- **대표 장면**: 출근길 남은 시간 23분 → 뉴스 요약 8분 + 경제 팟캐스트 15분을 자동 편성
- **핵심 기능**: NaviHelper 남은 시간 기반 편성, 정체로 시간이 늘면 콘텐츠 추가, 도착 직전 마무리
- **리스크**: 콘텐츠 수급, 음원 앱이 기능으로 넣기 쉬움

### 10. 통근 말하기 학습 ⚠️
- **대표 장면**: 신호대기 없이 달리는 고속 구간에서는 짧은 문장, 정체 구간에서는 롤플레이 대화
- **핵심 기능**: 주행 상태(속도·정체)에 따라 대화 난이도·길이 자동 조절, 정차 시에만 화면 복습
- **리스크**: 음성 SDK 준비 중 → Android 기본 음성 인식으로 대체해야 하고 "기술 활용성" 평가가 불확실

### 11. 도착 픽업 주문
- **대표 장면**: 퇴근길 "집 앞 반찬가게 7시 10분 도착" → 도착 시간에 맞춰 포장 완료
- **핵심 기능**: 경로상 매장 주문, ETA 기반 조리 시작, 정체 시 매장에 자동 지연 통보
- **리스크**: 배달·픽업 앱이 기능으로 넣을 수 있음, 시연은 Mock 매장
