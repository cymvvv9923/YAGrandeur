## 1. 공모전 소개

- 차량 데이터와 기능, 이동 상황을 활용해 **운전자와 탑승자에게 새로운 경험을 제공하는 앱 서비스**를 발굴·개발하는 공모전.
- 출퇴근, 여행, 충전, 주차, 가족과의 이동, 반려동물 동반, 휴식, 업무 등 차량을 이용하는 다양한 순간에 필요한 서비스를 자유롭게 제안.
- 자동차 = 이동 수단 + 위치·경로·주행 상태·차량 상태 등 데이터와 기능을 제공하는 **디지털 플랫폼**. 이를 활용해 차량 환경에서 유용한 앱을 만드는 것이 목표.

### 고객 니즈 · 페인포인트 예시 (주제 제한 없음, 별도 주제 구분 없이 자유 지원)

| 항목 | 구분 | 평가 내용 |

1. **1차 서류심사** — 위 기준으로 평가, 합격팀(20팀)은 공지사항으로 안내

3. **수상작 선정·순위 확정** — 2차 PT에서 제출·시연한 결과물 기준. 이후 추가 개발은 순위에 영향 없음
4. 제출된 결과물은 정상 구동·시연 가능 여부를 확인하며, 필요 시 보완 요청

### 추후 공지 예정 항목
- 2차 PT 심사 기준
- 수상팀(10팀) 전시 준비 기간의 준수사항 (수정·보완 범위, 추가 제출물과 기한)

### 최종 선정 10팀 의무
1. **전시 구동용 최종 APK 제출** (필수)
2. 선정작 전시 준비 — 앱 소개 영상 제작 협조, 현장 APK 시연 테스트
3. 2027.02 현대자동차그룹 공식 행사 **현장 참석·시연 및 시상식 참석 의무**

## 8. 개발 환경 (공모전 사이트 안내 요약)

> 상세 기술 정보와 링크는 `003_참고자료_모음.md` 참고

| 항목 | 요구사항 |
|---|---|
| Android | **minSdk API 28 이상** (에뮬레이터는 API 34 이미지) |
| Gradle | 8.0 이상 |
| 언어 | Java 또는 Kotlin |
| 실행 환경 | Pleos Connect Emulator (Android Studio AVD) + Virtual Console |

- **Pleos**: 현대자동차그룹의 소프트웨어 중심 모빌리티 브랜드
- **Pleos Connect**: 차량용 인포테인먼트 플랫폼 (Android Automotive OS 기반)
- **Pleos Playground**: Pleos 개발자 포털 — https://pleos.ai/playground

### Pleos Connect SDK (공모전에서 사용 가능한 SDK)

| 분야 | SDK |
|---|---|
| 차량 상태 | Vehicle SDK |
| 위치 정보 | FusedLocation SDK |
| 길 안내 연동 | NaviHelper SDK |
| 음성 입출력 | TextToSpeech SDK · SpeechToText SDK |

※ 각 SDK의 제공 상태와 사용 조건은 공식 문서에서 확인 (→ 참고자료 문서의 "SDK 제공 상태 주의" 참고)

### 공식 예시 시나리오 (참고용, 주제 제한 아님)
- **음성 메모 앱** — SpeechToText SDK로 운전 중 음성을 메모로 저장
- **안전운전 점수 앱** — Vehicle SDK 차량 상태 데이터로 주행 습관 점수화
- **배달 기사용 앱** — NaviHelper SDK로 경로 안내와 연동해 배달 동선 지원

FAQ 공식 권장 순서: Pleos Connect 환경 이해 → Playground 문서로 아이디어 기획 → Connect SDK로 개발. 접수양식 5번(개발 계획)에 SDK/API 사용계획을 **구체적으로** 작성.

## 10. 참가 규정 · 유의사항 (공지 "참가 및 출품 유의사항" 포함)

### 출품 · 접수
- 모든 출품작은 **순수 창작물**이어야 함. 표절작, **기 발표된 타 공모전 수상작은 심사 제외**
- 제출 서류 내용이 사실과 다르면 선정 취소 가능
- 마감 이후 제출 불인정. 파일 오류·파손 책임은 지원자
- 개인정보 오기재로 응모가 정상 완료되지 않으면 응모자 책임
- 마감 시각은 KST·사이트 서버 시각 기준

### 심사 · 시상 · 현장 시연
- 세부 심사기준 및 과정 비공개
- 일정은 주최 측 사정으로 변경 가능, 응모작 수·심사 기준에 따라 시상 작품 수 조정 또는 **수상작 없음** 가능
- 1차 합격팀(20팀)은 2차 PT에서 **실제 동작 가능한 앱 시연(에뮬레이터 또는 기기) 필수**
- 최종 10팀은 전시용 최종 APK 제출 + 2027.02 행사 현장 시연·시상식 **참석 의무**

### 지식재산권(IP)
- 출품 자료의 지식재산권은 **응모자에게 귀속**
- 단, **수상작**의 경우:
  - 주최 측은 수상 아이디어에 대한 **통상실시권**을 가질 수 있음 (대가·범위·기간은 상호 협의)
  - 주최 측은 결과 발표일로부터 **4개월간 지식재산권 양도 등에 대한 우선협상권**을 가질 수 있음
  - 주최 측은 비영리 공익 목적으로 입상작 복제·전송 가능, 별도 합의 시 2차적 저작물 작성 가능
- 제3자 권리(초상권, 저작권, 디자인권 등) 침해 시 책임은 응모자. 수상 후라도 표절·저작권 분쟁 시 **수상 취소 + 상금 전액 환수**
- **오픈소스 사용 시 라이선스 준수 및 출처 명시** (이용약관 제7조)
- 운영자는 출품작(기획서, 소스코드 등)을 심사·운영 목적 외로 사용·누설하지 않음 (비밀유지)

### 제출물 보관 · 폐기
- 요청 시 반환·폐기 가능. 별도 요청 없으면 2027.02.28 이후 즉시 폐기
- 수상작은 세무 증빙·후속 지원을 위해 2년 보유 후 폐기

### 이용약관 주요 내용
- 팀장이 모든 팀원에게 제출·심사·이용 동의를 받아야 하며, 요청 시 증빙 제출
- 팀 내 역할·기여도 분쟁은 팀 내부 해결
- 금지: 타인 계정·개인정보·저작물 무단 사용, 허위 기재, 사이트 자동화 수집, 취약점 악용 등 → 경고·이용정지·실격 가능
- 운영자는 출품작의 상품성, 차량 호환성, 사업화 가능성을 보증하지 않으며, 수상이 품질·안전성 인증을 의미하지 않음
- 대한민국 법령 적용
