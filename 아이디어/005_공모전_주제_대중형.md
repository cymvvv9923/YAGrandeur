# 대중형 + 독립 앱 주제 — "기능이 아니라, 새로 생기는 앱"

> 참고: `002_공모전_정보_총정리.md`, `003_참고자료_모음.md`, `004_공모전_주제_그랜저_PM관점.md`
> 목표: 매력적인 주제 + **최대한 많은 사용자** + **기존 앱의 기능이 아닌 완전히 새로운 앱** + 지금 쓸 수 있는 SDK(Vehicle 조회 + NaviHelper)로 구현 가능

---

## 1. 선정 조건 (6가지)

| 조건 | 체크 질문 |
|---|---|
| ① 전 운전자 대상 | 운전면허만 있으면 해당되나? |
| ② 자주 쓰는 순간 | 매일 또는 매주 쓰는 상황인가? |
| ③ 차종 무관 | 내연·HEV·EV 모두 되나? |
| ④ 자동 동작 | 입력 없이 차 상태로 알아서 켜지나? |
| ⑤ 지금 SDK로 구현 | Vehicle 조회 + NaviHelper로 되나? |
| ⑥ **독립 앱** ⭐ | 내비·멜론·마이현대에 "기능 하나"로 들어가면 끝나지 않나? |

### ⑥으로 다시 걸러본 이전 후보
| 이전 후보 | 판정 | 이유 |
|---|---|---|
| 장거리 휴식·휴게소 코파일럿 | ❌ | 내비의 기능 하나 (휴게소 추천은 내비가 하면 됨) |
| 주차 도우미 | ❌ | 내비·주차 앱의 기능 |
| 내 차 자동 가계부 | ⚠️ | 마이현대·블루링크 앱에 기능으로 들어갈 수 있음 (현대차가 직접 하기 쉬움) |
| 안전운전 점수 | ❌ | 공식 예시, 보험·마이현대 기능 |

**독립 앱이 되려면**: 기존 앱이 다루지 않는 **새로운 사용 시간**이나 **새로운 관계(커뮤니티)**를 만들어야 합니다.

## 3. 추천 주제 상세

### 🥇 A. 차 안 쉼 — "차를 가장 안전한 낮잠 공간으로"

- **한 줄 소개**: 차를 세우고 시트를 젖히면 자동으로 켜져, 안전 점검부터 기상까지 챙겨주는 차 안 휴식 앱
- **페인포인트**
  - 점심시간 차에서 낮잠 자는 직장인, 학원 픽업을 기다리는 학부모, 배송·영업 기사, 졸음쉼터의 장거리 운전자 등 **차에서 쉬는 사람이 매우 많음**
  - 그런데 차 안 휴식에는 위험이 있음: 내기순환 장시간 사용(환기 부족), 공회전 중 연료·배터리 소모, 문 잠금 확인, 너무 오래 자버림
  - 이걸 챙겨주는 앱은 휴대폰에도 차에도 없음 → **완전히 새로운 카테고리**
- **차량특화 (모바일이 절대 못 하는 것)**
  - **자동 진입**: 기어 P + 시트 등받이 각도가 뒤로 젖혀지면 휴식 모드 제안 (Seat 위치·각도 조회)
  - **안전 점검**
    - HVAC 내외기 상태 조회 → 내기순환 장시간이면 "환기하세요" 알림
    - Door 잠금, Window 열림 상태 확인
    - Fuel 잔량·EV 배터리 SOC → "이대로 공조를 켜두면 1시간에 배터리 약 N% 소모"
  - **기상**: 20분 파워냅 타이머, 백색소음, 알람 (조명 제어 SDK가 열리면 앰비언트 라이트로 서서히 깨우기 확장)
  - **기상 후**: 다음 목적지를 바로 내비로 연결 (NaviHelper)
- **주행·정차 맥락**: **정차 전용 앱**이라 주행 규제 부담이 거의 없고, 출발(기어 D)하면 자동 종료
- **사업성**
  - 타깃: 차에서 쉬는 모든 운전자. 직장인 점심 낮잠, 배송·대리·영업 기사, 장거리 운전자
  - 수익: 수면 사운드 프리미엄 구독, 기상 후 커피 쿠폰(경로상 매장 제휴), 졸음운전 예방 보험 연계
  - 리텐션: 점심 낮잠은 **매일 반복되는 습관**
- **PM이 좋아할 이유**
  - "차 = 이동 수단이 아니라 공간"이라는 SDV 비전을 가장 직관적으로 보여줌
  - 그랜저의 넓은 실내·시트 편의 사양을 상품성으로 연결
  - 안전(환기·배터리) 메시지가 있어 공익성도 확보
- **시연**: Virtual Console에서 기어 P, 공조 내기순환, 창문·도어 상태를 조작 → 앱이 반응하는 장면
- **확인 필요**: 시트 등받이 각도를 앱이 조회할 수 있는지, Virtual Console에서 각도를 조작할 수 있는지 (설명회 질문)

### 🥈 B. 드라이브로그 — "운전자를 위한 Strava"

- **한 줄 소개**: 내 모든 드라이브가 자동으로 기록되고, 좋은 드라이브 코스를 공유하면 다른 사람이 한 번 탭으로 그대로 달려보는 앱
- **페인포인트**
  - 주말 드라이브, 단풍·벚꽃 코스를 찾으려면 블로그를 검색하고 경유지를 하나하나 입력해야 함
  - 내 운전 기록(어디를 얼마나 달렸는지)이 남지 않음
- **차량특화**
  - **자동 기록**: 기어·도어 이벤트로 트립 시작·종료, Odometer TripStatistics(거리·시간), NaviHelper 목적지·경유지
  - **코스 실행**: 공유된 코스를 탭하면 `requestRouteWithWaypoints`로 경유지까지 한 번에 내비 실행 ← 차 안이라서 가능한 핵심 가치
  - **기록 카드**: 외기온도·주행거리·소요 시간·연비가 담긴 "오늘의 드라이브" 카드
  - 정복 지도·배지: 전국 시·도, 유명 고갯길·해안도로 달성
- **사업성**: 모든 운전자가 자동 기록으로 유입되고, 드라이브를 즐기는 층이 콘텐츠(코스)를 만듦 → 커뮤니티 성장 구조. 수익은 지역 관광 제휴, 코스 내 카페·맛집 광고
- **PM이 좋아할 이유**: App Market에 없는 **소셜 카테고리**이고, 사용자가 콘텐츠를 만들어 운영 비용 없이 성장
- **확인 필요**: 실제 주행 궤적은 FusedLocation SDK(준비 중)가 필요. 당장은 목적지·경유지 기반 코스로 구현

### C. 도착 맞춤 오디오 (보조 후보)
- NaviHelper 남은 시간에 맞춰 **도착할 때 딱 끝나는** 뉴스 요약·팟캐스트 조합을 큐레이션
- 독창적이지만 음원 앱이 기능으로 넣기 쉬워 ⑥에서 약함

---

## 4. 결론

- **1순위는 A. 차 안 쉼**입니다.
  - 기존 앱의 기능이 아니라 **"차에서 쉬는 시간"이라는 새로운 사용 시간**을 만드는 앱입니다.
  - 점심 낮잠처럼 매일 반복되고, 차종을 가리지 않으며, 정차 전용이라 규제 부담과 구현 난이도가 낮습니다.
  - 지금 쓸 수 있는 Vehicle 조회 데이터(기어·시트·공조·도어·창문·연료·배터리)만으로 핵심 기능이 완성됩니다.
- B. 드라이브로그는 커뮤니티 성장성이 커서 사업성 스토리가 좋지만, 위치 SDK가 열려야 완성도가 올라갑니다.
- 설명회에서 확인할 것: 시트 등받이 각도 조회 가능 여부, HVAC 내외기 상태 조회 가능 여부
