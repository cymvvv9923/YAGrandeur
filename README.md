## 길 위의 안부

서클(가족) 구성원이 폰 웹에서 메시지를 남기면, 차가 조건을 만났을 때 차에서 들려줍니다. 조건은 장소를 지날 때, 비 오는 날, 밤길, 옆자리에 누가 탄 날, 차에 탈 때 중에서 고릅니다. 하루 운전은 **차의 일기**로 남고, 본인이 허락한 항목만 서클에 보입니다.

실행 방법과 동작 설명은 [`apps/gil-wi-anbu/README.md`](apps/gil-wi-anbu/README.md)에 있습니다. 기능 소개 페이지는 [`docs/기능정리.html`](apps/gil-wi-anbu/docs/기능정리.html)입니다.

## 구현 현황 (2026-11-03 오후 갱신)

### ✅ 구현하고 에뮬레이터에서 확인함

**운전 흐름**
- 시동 후 "오늘 누가 운전하세요?"로 운전자를 고릅니다. 정차 중에만 뜹니다.
- 서버에서 서클과 메시지 목록을 받아옵니다.
- 내비 현재 위치로 근처 메시지를 차 안에서 계산합니다. 위치는 서버로 보내지 않습니다.
- 운전 중에 근처를 지나면 알림 "차를 세우면 들려드릴게요"를 띄우고, 메시지는 대기열에 모아 둡니다.
- 정차(P)하면 재생 화면과 재생 알림이 뜹니다. 끝까지 들으면 「들었어요」가 자동으로 전송되고 서클 소식에 반영됩니다.
- 출발(D)하면 기본 내비로 바뀌고 열린 입력 창이 닫힙니다.
- 후진(R)일 때는 후방 카메라를 가리지 않도록 내비를 띄우지 않습니다.
- 쉬어간 횟수는 P→D→R→P만 셉니다. P→R→P는 세지 않습니다.
- 앱이 강제로 꺼졌다 켜져도 그날 받은 메시지는 다시 재생합니다.

**메시지가 열리는 조건**

| 조건 | 차 신호 |
| :-- | :-- |
| 📍 이 장소를 지나면 | 내비 위치 |
| 🌧 비 오는 날 | 앞 와이퍼 |
| 🌙 밤길 | 하향등 |
| 👥 옆자리에 누가 탄 날 | 조수석 탑승 센서 |
| 🚪 차에 탈 때 | 운전석 문 |

같은 메시지는 하루에 한 번만 열립니다.

**일기와 공유**
- 홈 화면은 일기 중심입니다.
- 일기에는 달린 거리, 쉬어간 횟수, 들은 메시지, 비·밤길, 동승 여부가 들어갑니다.
- 공유 설정은 기본으로 꺼져 있고, 켠 항목만 서버로 보냅니다. 동승 여부는 공유하지 않습니다.
- 메시지 키워드 필터가 있습니다.

**목소리 메시지와 알림 버튼** (11-03 확인)
- 차에서 녹음해 남기면 서버에 올라가고, 다른 사람이 운전할 때 재생되고 「들었어요」가 갑니다.
- 서버에 올린 목소리 파일(wav)을 차에서 재생하고, 끝까지 들으면 자동으로 「들었어요」를 보냅니다.
- 재생 알림의 「들었어요」「보내지 않기」「나중에」 버튼을 직접 눌러 확인했습니다.

**관리와 폰 웹**
- 사용자 관리: 구성원 추가, 순서 바꾸기, 빼기, 이름 바꾸기. 서클 이름·종류 바꾸기.
- 신고하면 메시지가 목록에서 숨겨집니다. 금지어 이름은 거절합니다.
- 폰 웹에서 조건을 골라 메시지를 남길 수 있습니다. 에뮬레이터 안 브라우저에서도 동작합니다.

**글 → 음성 (TTS)**
- 실차에서 우리말 TTS와 소리를 팀원이 확인했습니다 (안드로이드 TTS 방식).
- 11-03부터 내비 안내 음성과 같은 **Pleos TTS SDK**를 먼저 쓰고, 안 되면 안드로이드 TTS로 바꿔 다시 읽습니다. 에뮬레이터에는 음성 모델이 없어 소리는 실차에서 확인해야 합니다.

### ⚠️ 코드는 있지만 시험이 덜 됨

| 기능 | 남은 일 |
| :-- | :-- |
| 차에서 🎤 말로 적기 | 에뮬레이터 음성 인식(`ai.umos.ambientai`)이 응답하지 않아 5초 뒤 안내만 확인했습니다. **실차 시험 필요** |
| 폰 웹 🎤 말로 적기 | 버튼 표시까지만 확인했습니다. 실제 폰에서 시험 필요 |
| 들러 가기 (내비 경유지) | 내비가 요청을 받는 것까지 확인했습니다. 경로 안내 중 화면에 반영되는지는 미확인 |
| Pleos TTS SDK로 읽기 | 연결·준비·읽기 요청까지 확인. 에뮬레이터에 음성 모델이 없어 소리는 **실차 확인 필요** |
| 조수석 탑승 값 방향 | 에뮬레이터는 값이 반대로 들어와 보정해 두었습니다(`OCCUPANCY_INVERTED`). 실차에서 확인 필요 |
| 폰 웹 녹음(webm) → 차에서 재생 | wav와 차에서 녹음한 m4a는 확인. 폰 웹이 만드는 webm은 시험 파일이 없어 미확인 |
| 차에서 신고 버튼, 서클 종류를 연인·친구로 바꿀 때 일기 공유 꺼짐 | 서버 동작은 확인, 차 화면에서 누르는 것은 미시험 |

### ⬜ 미구현

| 기능 | 비고 |
| :-- | :-- |
| **서버 배포** | 지금은 PC(`localhost:8090`)에서만 돌아서 실차가 접속할 수 없습니다. 인터넷에 올리고 `car-app/app/build.gradle.kts`의 `SERVER_URL`을 바꿔야 합니다. **실차 시연 전 필수** |
| 로그인 / 사용자 구분 | 누구나 아무 구성원이나 고를 수 있습니다 |
| 서클 여러 개 | "우리집" 서클 하나뿐입니다 |
| 가족 모드 (운전자가 켜고 끄기) | 논의만 하고 보류했습니다 |
| 다른 사람이 탔을 때 처리 | 운전자 재확인, PIN, 게스트 모드 모두 없습니다 |
| 뒷좌석 탑승 판단 | 센서가 없는 차가 많아 제외했습니다 |
| 팀 문서 아이디어 (이맘때 추천 등) | 반영하지 않았습니다 |

### 에뮬레이터의 한계

- 속도를 올려도 누적 주행거리가 늘지 않습니다. 시연 스크립트(`demo.ps1`)가 콘솔로 주행거리를 올립니다.
- 내비 위치가 고정이라 `geo fix`를 따르지 않습니다. 시연용 `DemoReceiver`로 위치를 바꿉니다.
- TTS와 음성 인식이 동작하지 않습니다(음성 모델 없음). 실차에서는 TTS가 됩니다.
- 마이크는 `adb emu avd hostmicon`으로 PC 마이크를 연결해야 녹음됩니다.
